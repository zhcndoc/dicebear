# 支持 DiceBear

DiceBear 免费且采用 MIT 许可证。它没有付费层级，也没有公司支持。如果你在使用它并希望有所回馈，可以选择以下几种方式。

## 为仓库点星

点星无需任何费用，还能让项目更容易被下一个
寻找头像库的人发现。

- [dicebear/dicebear](https://github.com/dicebear/dicebear)：六种语言的核心库、
  CLI、本文档站点以及编辑器
- [dicebear/styles](https://github.com/dicebear/styles)：头像样式
  定义
- [dicebear/api](https://github.com/dicebear/api)：可自行托管的 HTTP API

## 贡献

欢迎在所有代码仓库中提交错误报告和拉取请求。
[为库做贡献](/guides/contribute-to-the-library/)介绍了每种更改应归属的位置，
以及如何在本地设置项目。

新的头像样式是用户最容易注意到的贡献内容。这里有关于[使用 Figma 创建样式](/guides/create-an-avatar-style-with-figma/)和[从头开始创建头像样式](/guides/create-an-avatar-style-from-scratch/)的指南。

## 帮助其他用户

集成相关的问题会通过
[GitHub Discussions](https://github.com/dicebear/dicebear/discussions) 提出。其中大多数问题，任何在实际项目中使用过 DiceBear 的人都可以回答。
