# Cutouts

Cutouts 是一种纸张拼贴头像风格。每张脸都由撕裂的手工纸拼合而成：彩色的头部、覆盖其上的头发，以及分别剪裁出的眼睛、鼻子和嘴巴。两只眼睛从不匹配，这正是这种风格的特点。为社区和编辑类网站生成温暖、手工制作感十足的个人资料图片。
