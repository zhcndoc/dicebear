# Clay

Clay 是一种柔和的矢量头像风格，由圆润的块状形体组成，看起来像是用黏土捏制而成，配有简洁的面孔、顶部的小角或卷曲，以及压入表面的纹理。为聊天应用和社区个人资料生成温暖的 SVG 头像图标。
