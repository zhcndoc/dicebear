# Line Face

Line Face 用几笔笔触勾勒出一张脸，除此之外不添加任何其他元素。八种眼睛组合、六种鼻子和八种嘴巴，每种都只用一笔绘制，直接置于温暖的背景上，周围没有头部轮廓。为阅读应用和个人网站生成安静、简约的个人资料图标。
