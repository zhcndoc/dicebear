# 星座

星座是一种夜空矢量头像风格，将几颗明亮的星星连接成独特的星图，
同时搭配散布在背景中的星星和偶尔出现的彗星。为深色界面和创意项目生成宁静而
独具特色的 SVG 个人资料图标。
