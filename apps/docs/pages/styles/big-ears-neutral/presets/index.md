# Big Ears Neutral 预设

这里的每个预设都是一组普通的渲染选项。无需安装任何内容，同样的值可在全部六个库中使用，也可作为 HTTP-API 查询参数使用。选择一个预设来查看其代码，或在 playground 中打开它并随意更改。

预设未设置的选项会继续随 seed 变化，因此其中大多数仍会像普通风格一样，为每位用户保持独特。每个预设都会列出它仍能生成多少个不同的头像。
