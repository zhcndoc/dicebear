# Bottts Neutral 预设

这里的每个预设都是一组普通的渲染选项。无需安装任何内容，相同的值在全部六个库中以及作为 HTTP-API 查询参数时都适用。选择一个来查看其代码，或在 playground 中打开它并随意更改。

预设未设置的选项会继续随 seed 变化，因此其中大多数预设仍会像普通样式一样，为每位用户保持唯一。每个预设都会列出它仍能提供多少个不同的头像。
